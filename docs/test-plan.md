# MVP 冒烟测试计划

最后更新：2026-05-13

## 目标

第一阶段目标是确认当前 mock 版微信小程序 MVP 可以被导入、编译、浏览和完成核心交互闭环。测试重点不是覆盖所有边界，而是尽早发现阻断首屏、路由、发布、回应、本地存储和 Agent 对话的基础问题。

## 测试环境

- 工具：微信开发者工具。
- 项目类型：微信原生小程序。
- 项目目录：仓库根目录。
- AppID：可使用 `project.config.json` 中配置的 AppID，或导入时改用测试号。
- 数据来源：`services/mockData.js`、本机 `wxStorage`，以及可选微信云数据库。

## 已执行的源码级检查

- JS 语法检查：对所有 `.js` 文件执行 `node --check`，结果通过。
- JSON 解析检查：对所有 `.json` 文件执行 JSON 解析，结果通过。
- 路由文件检查：`app.json` 中注册的页面均存在 `.js`、`.json`、`.wxml`、`.wxss` 文件。
- Tab 图标检查：`app.json` 中声明的底部导航图标文件均存在。
- 服务层冒烟检查：创建公开帖、创建私密帖、提交回应、刷新回应数、读取我的发布、发送 Agent 消息均通过。
- 小队服务层检查：搜索小队、加入小队、退出小队均通过。
- 举报服务层检查：举报帖子可生成本地待处理记录。
- Agent 权限服务层检查：关闭全部权限时 Agent 回复仅基于本次输入；开启全部权限时 Agent 回复来源包含本人发布/回应和小队公开内容。
- 急性期支持服务层检查：输入冲动内容后可以创建本地缓冲记录，并能恢复记录数。
- 安全提醒服务层检查：选择“担心安全”或输入高风险表达时，急性期支持记录会标记安全提醒；Agent 收到高风险表达时回复来源为“安全提醒”。
- 联系决策服务层检查：输入草稿后可以生成本地联系判断记录；高冲动且无现实必要性时建议暂停；高风险表达时优先生成安全提醒。
- 关系复盘服务层检查：输入关系事件和核心需求后可以生成结构化复盘记录。
- 断联计划服务层检查：输入断联目标和替代动作后可以生成 7/14/30 天断联计划记录。
- 云持久化 fallback 检查：未配置 `CLOUD_ENV_ID` 时，帖子、回应、Agent 消息、冲动缓冲、联系判断、关系复盘、断联计划和举报仍可通过本地兜底创建。
- 用户资料 fallback 检查：未配置 `CLOUD_ENV_ID` 时，昵称、头像占位、阶段和个人备注仍可保存到本地并恢复。

## 本轮修复

- 修复本地 ID 冲突风险：原先帖子、回应和 Agent 消息使用 `Date.now()` 生成 ID，连续快速创建时可能出现毫秒级重复。现在统一通过 `utils/id.js` 的 `createLocalId(prefix)` 生成本地 ID，降低重复 ID 导致的列表渲染、可见性判断和评论关联风险。

## 手动冒烟测试清单

### 1. 导入与编译

- 使用微信开发者工具导入仓库根目录。
- 确认项目可编译运行。
- 确认控制台没有阻断首屏渲染的错误。
- 首屏应进入首页，并显示「失恋阵线联盟」。

### 2. 底部导航

- 点击首页、互助会、Agent、我的四个底部 Tab。
- 每个 Tab 应正常切换，页面标题和内容应匹配。
- Tab 图标选中态应正常切换。

### 3. 首页

- 确认首页展示品牌标题、产品定位和服务边界提示。
- 确认推荐阵线小队和最新公开内容流正常渲染。
- 点击推荐小队，应进入对应小队详情。
- 点击公开内容，应进入帖子详情。
- 点击「找 Agent 聊聊」，应切换到 Agent Tab。
- 点击「我现在很难受」，应进入急性期支持页。
- 点击「我要不要联系 TA？」，应进入联系决策页。

### 3.1 急性期支持

- 页面应展示「先撑过这 10 分钟」。
- 页面应展示非医疗/非紧急救助边界和紧急安全提醒。
- 可以选择冲动类型：想联系 TA、深夜撑不住、一直自责、担心安全。
- 选择「担心安全」后，应展示醒目的安全提醒。
- 输入高风险表达后，应展示醒目的安全提醒。
- 空内容点击「先存下」，应提示「先写下这股冲动」。
- 输入想发出去的话后点击「先存下」，应显示成功反馈。
- 保存高风险表达后，保存结果应提示优先处理安全。
- 保存后应出现在「最近暂存」列表。
- 点击「最近暂存」中的记录，应展开并展示完整暂存内容。
- 再次点击已展开记录，应收起内容。
- 保存后应展示本次冲动类型和 10 分钟缓冲步骤。
- 重新进入页面后，已记录次数应恢复。
- 点击「找 Agent 陪我说完整」，应切换到 Agent。
- 点击「判断要不要联系 TA」，应进入联系决策页。
- 点击「发到阵线小队」，应进入发布页。

### 3.2 联系决策

- 页面应展示「复盘关系，守住边界」。
- 页面应展示三个页签：联系判断、结构复盘、断联计划。
- 可以选择联系目的、冲动强度、是否有现实事务和已经等待的时长。
- 空草稿点击提交，应提示「先写下想联系的内容」。
- 高冲动且没有现实事务时，应生成“不建议立刻联系”类型建议。
- 有现实事务或确认边界时，应生成“可以准备，但先保持边界”类型建议。
- 输入高风险表达时，应优先生成安全提醒，不给普通联系建议。
- 切到「结构复盘」后，空事件或空需求点击提交，应提示补充事件和需求。
- 填写关系事件、核心需求、重复模式和证据后，应生成结构化复盘结果。
- 切到「断联计划」后，空目标或空替代动作点击提交，应提示补充目标和替代动作。
- 选择断联周期、风险时段、保护动作并填写目标后，应生成断联计划、起止日期、执行规则和破戒预案。
- 重新进入页面后，已记录次数应恢复。
- 点击「先撑 10 分钟」，应进入急性期支持页。
- 点击「找 Agent 继续复盘」，应切换到 Agent。

### 4. 互助会与小队详情

- 互助会页应展示所有阵线小队，包括标签、成员数、今日活跃数、氛围和加入状态。
- 在搜索框输入小队名称、简介或标签关键字，应只展示匹配小队。
- 点击小队卡片上的加入/已加入状态，应切换加入或退出状态。
- 点击任意小队，应进入小队详情。
- 小队详情应展示简介、标签、成员概览信息和公开内容。
- 小队详情应支持加入/退出当前小队。
- 点击「发布到小队」，应进入发布页并显示目标小队。
- 点击「找 Agent 复盘」，应切换到 Agent Tab。

### 5. 发布

- 切换内容类型：倾诉、复盘、求建议。
- 切换情绪标签。
- 切换可见范围：小队可见、仅自己和 Agent 可见。
- 空正文点击发布，应提示「先写下一点内容」。
- 输入正文后发布，应显示成功反馈并返回上一页。
- 如果先在我的页修改昵称，新发布内容的作者应使用当前昵称。
- 发布「小队可见」内容后，应能在对应小队详情或首页公开流看到。
- 发布「仅自己和 Agent 可见」内容后，不应出现在公开流，但应出现在「我的发布」。

### 6. 帖子详情与回应

- 帖子详情应展示正文、所属小队、情绪标签、相对时间和回应数。
- 点击帖子举报入口，应弹出举报原因并可提交。
- 空回应提交，应提示「先写下一点回应」。
- 输入回应后提交，应显示成功反馈。
- 如果先在我的页修改昵称，新回应的作者应使用当前昵称。
- 新回应应追加到回应列表顶部。
- 点击回应举报入口，应弹出举报原因并可提交。
- 帖子回应数应同步增加。
- 点击所属小队入口，应返回对应小队详情。

### 7. Agent

- Agent 页应展示初始 mock 对话。
- 页面应展示服务边界提示和上下文说明。
- 页面应展示当前 Agent 上下文授权范围。
- 点击「我怕自己会冲动，先撑 10 分钟」，应进入急性期支持页。
- 输入消息并发送后，用户消息应追加到列表。
- Agent 应返回一条 mock 关怀回复。
- Agent 回复来源说明应与当前权限一致。
- 输入高风险表达后，Agent 回复来源应显示「安全提醒」，并优先引导联系现实中的可信赖支持或紧急救助渠道。
- 对话应自动滚动到最新消息。

### 8. 我的

- 我的页应展示用户资料、已加入小队和我的发布。
- 我的页应展示当前资料来源：云端账户或本地访客。
- 点击头像区域选择头像后，头像预览应更新。
- 修改昵称后，头像占位字应随昵称首字更新。
- 选择当前阶段后，被选阶段应高亮。
- 输入个人备注后点击「保存资料」，应提示保存成功。
- 重新进入我的页后，昵称、头像、阶段和备注应恢复。
- 点击「同步微信资料」后，如授权成功应写入微信昵称/头像；如取消或环境不支持，应提示可手动编辑。
- 点击「切回匿名资料」后，应恢复匿名昵称、默认头像占位、急性期和空备注。
- 点击已加入小队，应进入小队详情。
- 点击我的发布，应进入帖子详情。
- Agent 权限说明应展示「参考本人发布」和「参考小队公开内容」。
- 关闭「参考本人发布和回应」后，回到 Agent 页应显示不参考个人发布和回应。
- 关闭「参考小队公开内容」后，回到 Agent 页应显示不参考小队公开内容。
- 关闭全部权限后发送消息，Agent 回复来源应显示「仅基于本次输入」。
- 重新开启权限后发送消息，Agent 回复来源应恢复为包含授权上下文。
- 非医疗/非心理咨询服务边界提示应可见。

### 9. 本地持久化

- 发布一条公开帖、一条私密帖、一条回应，并发送一条 Agent 消息。
- 关闭并重新打开小程序。
- 确认本机创建的公开帖、私密帖、回应和 Agent 对话仍能恢复。
- 如需重测初始状态，可在微信开发者工具中清理本地缓存后重新编译。

## 通过标准

- 应用可导入并编译运行。
- 四个底部 Tab 和所有详情/发布路由可正常进入。
- 发布、回应和 Agent 发送链路均可完成。
- 本地创建的数据在重新进入小程序后仍存在。
- 私密内容不进入公开内容流。
- Agent 和我的页面均展示非医疗/非心理咨询边界提示。

## 未覆盖范围

- 真机兼容性、性能、弱网体验和长列表压力测试。
- 微信云开发环境中的真实数据库写入、云函数部署验证和 OpenAI-compatible API 实际请求。
- 微信资料授权真机兼容性、云端权限规则和内容审核。
- 自动化回归测试和 CI；当前仓库尚未配置相关工具链。

## 云端回归补充

配置 `CLOUD_ENV_ID`、部署 `dataStore` / `aiAgent` 云函数并设置 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL` 后，需要补充验证：

- 发布帖子后，`ha_posts` 出现对应记录。
- 提交回应后，`ha_comments` 出现对应记录，帖子回应数更新。
- 发送 Agent 消息后，`ha_agent_messages` 出现用户消息和 Agent 回复。
- 保存个人资料后，`ha_users` 出现或更新当前 OpenID 对应记录。
- 加入/退出小队后，`ha_users.joinedCommunityIds` 更新。
- 提交举报后，`ha_reports` 出现对应待处理记录。
- Agent 回复来源显示 `AI推理 · ...`。
- 保存急性期缓冲后，`ha_urge_records` 出现对应记录。
- 保存联系判断、结构化复盘或断联计划后，`ha_review_records` 出现对应记录，且 `kind` 区分记录类型。
- 清理本地缓存后重新进入，小程序仍能从云端恢复个人资料和用户生成数据。
