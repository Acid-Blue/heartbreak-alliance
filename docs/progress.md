# 进度文档

最后更新：2026-05-11

## 当前状态

当前仓库已经实现一个可运行的微信原生小程序 MVP，数据来源为本地 mock 和本机存储。核心产品框架已落地：首页、互助会、小队详情、帖子详情、发布、Agent、我的页面均已在 `app.json` 注册，并通过 `services/` 下的服务层提供数据。

第一阶段 MVP 验收工作已开始，冒烟测试计划见 `docs/test-plan.md`。本轮已完成源码级检查和服务层冒烟验证，但尚未执行微信开发者工具编译、模拟器或真机验证。

## 已实现需求

- 应用外壳：`app.js`、`app.json`、`app.wxss` 已定义小程序入口、全局样式、品牌标题和四个底部 Tab：首页、互助会、Agent、我的。
- 首页：展示品牌、产品定位、推荐阵线小队、最新公开内容、服务边界提示，并支持进入小队、帖子和 Agent。
- 互助会：展示所有 mock 小队，包括主题、标签、成员数、今日活跃数、氛围和加入状态；小队详情页展示小队信息和公开帖子。
- 发布：支持选择内容类型（`倾诉`、`复盘`、`求建议`）、情绪标签、可见范围、正文校验、成功反馈和本地持久化。
- 帖子详情：展示正文、小队入口、情绪、相对时间、回应数和已有回应；支持提交本地回应并刷新回应数。
- Agent：展示初始 mock 对话、说明上下文边界、支持用户输入、追加 mock 关怀回复、滚动到最新消息，并持久化本地对话。
- 我的：展示 mock 用户资料、已加入小队、我的发布、Agent 权限说明，以及非医疗/非心理咨询服务边界提示。
- 数据层：`communityService`、`postService`、`agentService`、`userService` 均返回 Promise，并将页面层与 mock/本地存储实现隔离。
- 持久化：本机创建的帖子、回应和 Agent 消息通过 `utils/localStore.js` 使用 `wxStorage` 保存；在非微信环境下有内存兜底。

## 部分实现

- Agent 上下文已在界面说明，但 mock 回复目前只使用用户最新输入，并未真正汇总用户帖子、评论或小队公开内容。
- Agent 授权和权限状态目前是固定 mock 展示，尚未提供修改授权的设置流程。
- 可见范围会影响本地新建帖子的公开流展示，但还没有服务端隐私模型或内容治理流程。
- 关键页面已经有加载、空状态和错误状态，但本次没有在微信开发者工具中逐项验证。

## 尚未实现

- 云开发、真实数据库、真实 AI 模型接入、登录认证和用户身份持久化。
- 危机或高风险表达识别；当前只有静态安全边界文案。
- 加入/退出小队、通知、搜索、内容审核工具、私信、支付或后台管理能力。
- 自动化测试、CI、覆盖率报告和命令行构建/测试脚本。

## 验证说明

本次进度判断基于对 `docs/spec/`、`app.json`、`pages/`、`services/`、`utils/` 的源码检查。已执行 JS 语法检查、JSON 解析检查、页面/Tab 图标文件存在性检查和服务层冒烟检查。

服务层冒烟检查覆盖公开帖创建、私密帖创建、回应提交、回应数刷新、我的发布读取和 Agent 消息发送。本轮发现并修复了本地 ID 使用 `Date.now()` 导致的快速创建冲突风险，改为通过 `utils/id.js` 统一生成本地 ID。

尚未运行微信开发者工具编译、模拟器冒烟测试或真机预览。
