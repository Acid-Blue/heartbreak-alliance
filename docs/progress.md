# 进度文档

最后更新：2026-05-13

## 当前状态

当前仓库已经实现一个可运行的微信原生小程序 MVP，数据来源为本地 mock、本机存储和可选微信云开发。核心产品框架已落地：首页、互助会、小队详情、帖子详情、发布、Agent、我的页面均已在 `app.json` 注册，并通过 `services/` 下的服务层提供数据。

云持久化与 AI 推理边界已接入，配置说明见 `docs/cloud-ai-setup.md`。配置微信云环境后，用户生成数据会优先写入云数据库；配置 `OPENAI_API_KEY`、`OPENAI_BASE_URL` 和 `OPENAI_MODEL` 后，Agent 可通过云函数调用 OpenAI-compatible Chat Completions API。未配置云环境或云函数失败时，仍回退到本地 mock / `wxStorage`，保证本地开发可用。

第一阶段 MVP 验收已完成，冒烟测试计划见 `docs/test-plan.md`。本轮已完成源码级检查、服务层冒烟验证和微信开发者工具人工冒烟测试。

用户画像及问题定义已纳入长期路线图，见 `docs/spec/user-problem.md` 和 `docs/roadmap.md`。后续工作将按急性期支持、关系复盘、同伴社群、生活重建和真实数据/AI 基础设施分阶段推进。

## 已实现需求

- 应用外壳：`app.js`、`app.json`、`app.wxss` 已定义小程序入口、全局样式、品牌标题和四个底部 Tab：首页、互助会、Agent、我的。
- 首页：展示品牌、产品定位、推荐阵线小队、最新公开内容、服务边界提示，并支持进入急性期支持、联系决策、小队、帖子和 Agent。
- 急性期支持：提供“先撑过 10 分钟”页面，支持选择冲动类型、暂存想发出去的话、点开最近暂存记录、查看缓冲步骤、进入 Agent 或发布到阵线小队。
- 联系决策：提供“复盘关系，守住边界”页面，支持联系判断、结构化关系复盘和断联计划，并生成保守下一步建议。
- 互助会：展示所有 mock 小队，包括主题、标签、成员数、今日活跃数、氛围和加入状态；支持搜索、加入/退出小队；小队详情页展示小队信息和公开帖子。
- 发布：支持选择内容类型（`倾诉`、`复盘`、`求建议`）、情绪标签、可见范围、正文校验、成功反馈和本地持久化。
- 帖子详情：展示正文、小队入口、情绪、相对时间、回应数和已有回应；支持提交本地回应并刷新回应数。
- 举报：帖子详情支持举报帖子和回应，记录可写入云数据库，云不可用时写入本地。
- Agent：展示初始 mock 对话、说明上下文边界、展示当前授权范围、支持用户输入、按授权范围追加 mock 关怀回复、滚动到最新消息，并持久化本地对话。
- 我的：展示登录/资料状态、头像、昵称、当前阶段、个人备注、已加入小队、我的发布、Agent 权限开关，以及非医疗/非心理咨询服务边界提示。
- 数据层：`communityService`、`postService`、`agentService`、`userService` 均返回 Promise，并将页面层与 mock/本地存储实现隔离。
- 登录与资料：支持基于微信云开发 OpenID 的云端身份、微信资料授权入口、头像选择、昵称输入、阶段选择、个人备注保存和切回匿名资料。
- 持久化：用户资料、用户创建的帖子、回应、Agent 消息、Agent 权限设置、冲动缓冲记录、联系判断、关系复盘、断联计划和举报记录已支持云端持久化；云不可用时通过 `utils/localStore.js` 使用 `wxStorage` 兜底。

## 部分实现

- Agent 上下文已接入本人发布、本人回应和所在小队公开内容摘要，但仍是 mock 回复，不是真实 AI 推理。
- Agent 已接入云函数 AI 推理边界；真实推理依赖云函数环境变量 `OPENAI_API_KEY`，endpoint 由 `OPENAI_BASE_URL` 控制，未配置时仍回退到 mock 回复。
- 急性期支持已有静态安全提醒、冲动缓冲流程和保守关键词安全提醒，但尚未做深夜模式、紧急联系人或完整安全策略。
- 联系决策已支持基础决策辅助、结构化关系复盘和断联计划，但尚未支持连续行动计划、断联进度追踪或周期回顾。
- 可见范围会影响本地新建帖子的公开流展示，但还没有服务端隐私模型或内容治理流程。
- 关键页面已经有加载、空状态和错误状态，并已通过本轮人工冒烟测试覆盖主流程；更细的异常分支仍需后续回归时补充。

## 尚未实现

- 完整危机安全策略；当前只有关键词触发的保守安全提醒，不做诊断、风险分级或自动干预。
- 通知、完整内容审核后台、私信、支付或后台管理能力。
- 覆盖率报告和更完整的端到端自动化测试。
