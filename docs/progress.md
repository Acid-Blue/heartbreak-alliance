# 进度文档

最后更新：2026-05-16

## 当前状态

当前仓库已经实现一个可运行的微信原生小程序 MVP，数据来源为本地 mock、本机存储和可选微信云开发。核心产品框架已落地：首页、急性期支持、关系复盘、互助会、小队详情、帖子详情、发布、Agent、我的、内容治理页面均已在 `app.json` 注册，并通过 `services/` 下的服务层提供数据。

云持久化与 AI 推理边界已接入，配置说明见 `docs/cloud-ai-setup.md`。配置微信云环境后，用户生成数据会优先写入云数据库；配置 `OPENAI_API_KEY`、`OPENAI_BASE_URL` 和 `OPENAI_MODEL` 后，Agent 可通过云函数调用 OpenAI-compatible Chat Completions API。未配置云环境或云函数失败时，仍回退到本地 mock / `wxStorage`，保证本地开发可用。

第一阶段 MVP 验收已完成，冒烟测试计划见 `docs/test-plan.md`。本轮已完成源码级检查、服务层冒烟验证和微信开发者工具人工冒烟测试。

用户画像及问题定义已纳入长期路线图，见 `docs/spec/user-problem.md` 和 `docs/roadmap.md`。本轮已把急性期支持、关系复盘、同伴社群、生活重建和治理基础设施的 MVP 版本补齐；真实生产环境仍需微信云环境、模型 Key、权限规则和运营流程实测。

## 已实现需求

- 应用外壳：`app.js`、`app.json`、`app.wxss` 已定义小程序入口、全局样式、品牌标题和四个底部 Tab：首页、互助会、Agent、我的。
- 首页：展示品牌、产品定位、推荐阵线小队、最新公开内容、服务边界提示，并支持进入急性期支持、联系决策、小队、帖子和 Agent。
- 急性期支持：提供“先撑过 10 分钟”页面，支持冲动缓冲、深夜模式、安全计划、可信赖联系人、最近暂存、安全提醒、进入 Agent/联系决策/发布。
- 联系决策：提供“复盘关系，守住边界”页面，支持联系判断、结构化关系复盘、断联计划、行动计划、进度打卡和 7 天周期回顾。
- 互助会：展示所有 mock 小队，包括主题、标签、阶段匹配、成员数、今日活跃数、氛围和加入状态；支持搜索、加入/退出小队；小队详情页展示分享模板、正向回应引导、阶段打卡和公开帖子。
- 发布：支持选择内容类型（`倾诉`、`复盘`、`求建议`）、情绪标签、可见范围、正文校验、内容提示、审核标记、成功反馈和本地持久化。
- 帖子详情：展示正文、小队入口、情绪、相对时间、回应数和已有回应；支持回应模板、敏感内容提示、提交本地回应并刷新回应数。
- 举报与治理：帖子详情支持举报帖子和回应，记录可写入云数据库，云不可用时写入本地；被举报内容会在本机隐藏；内容治理页支持查看举报并标记处理中、已处理或不处理。
- Agent：展示初始 mock 对话、说明上下文边界、展示当前授权范围、支持用户输入、按授权范围参考本人发布/回应、行动追踪、生活重建、小队公开内容摘要，滚动到最新消息，并持久化本地对话。
- 我的：展示登录/资料状态、头像、昵称、当前阶段、个人备注、已加入小队、我的发布、生活重建任务与趋势、Agent 权限开关、内容治理入口，以及非医疗/非心理咨询服务边界提示。
- 数据层：`communityService`、`postService`、`agentService`、`userService` 均返回 Promise，并将页面层与 mock/本地存储实现隔离。
- 登录与资料：支持基于微信云开发 OpenID 的云端身份、微信资料授权入口、头像选择、昵称输入、阶段选择、个人备注保存和切回匿名资料。
- 持久化：用户资料、用户创建的帖子、回应、Agent 消息、Agent 权限设置、安全计划、冲动缓冲记录、联系判断、关系复盘、断联计划、行动追踪、生活重建记录、社群打卡和举报记录已支持云端持久化；云不可用时通过 `utils/localStore.js` 使用 `wxStorage` 兜底。
- 工程化：已新增 GitHub Actions workflow，push 和 pull request 会运行 `npm test`。

## 部分实现

- Agent 已接入云函数 AI 推理边界；真实推理依赖云函数环境变量 `OPENAI_API_KEY`，endpoint 由 `OPENAI_BASE_URL` 控制，未配置时仍回退到 mock 回复。

- 可见范围、审核标记和举报隐藏已影响公开流展示；生产级内容治理仍需要服务端权限、运营审核角色和云端规则实测。
