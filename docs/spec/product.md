# Product Spec

## Product

「失恋阵线联盟」是一个失恋后同伴互助小程序。产品以固定的“阵线小队”为组织单元，让用户在安全、克制的空间中倾诉、复盘、求建议，并通过个人 Agent 获得持续关怀。

## Target Users

- 正在经历分手、暧昧结束、关系断联或情绪反复的人。
- 希望被同路人理解，而不是立刻接受强建议或专业诊断的人。
- 愿意把自己的经历转化为复盘、互助和生活秩序重建的人。

详细用户画像、核心痛点和用户任务见 `docs/spec/user-problem.md`。

## MVP Goals

- 搭建可运行的微信原生小程序框架。
- 明确“阵线小队、内容流、发布、Agent、我的”五类核心体验。
- 用 mock 数据跑通首版页面和服务接口。
- 为未来云开发、真实 AI 模型和内容治理预留边界。

长期路线图见 `docs/roadmap.md`。路线图将用户画像拆分为急性期支持、关系复盘、同伴社群、生活重建和真实数据/AI 基础设施等阶段。

## Non Goals

- 不做心理咨询、医疗诊断或危机干预服务。
- 不做会员付费、广告曝光、专家入驻或预约交易。
- 不做真实社交关系链、私信或通讯录读取。
- 不接真实 AI 模型和真实云数据库。

## Core Journey

1. 用户进入首页，理解「失恋阵线联盟」和推荐阵线小队。
2. 用户进入互助会，浏览固定小队和小队公开内容。
3. 用户发布倾诉、复盘或求建议内容。
4. 用户在 Agent 页收到基于本人内容和小队公开内容的温和关怀。
5. 用户在我的页查看加入的小队、自己的内容和 Agent 权限说明。
