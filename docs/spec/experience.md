# Experience Spec

## Navigation

底部导航固定为四项：

- 首页
- 互助会
- Agent
- 我的

详情页和发布页通过页面跳转进入，不出现在底部导航中。

急性期支持页通过首页和 Agent 页进入，不出现在底部导航中。

联系决策页通过首页和急性期支持页进入，不出现在底部导航中。

## Pages

### 首页

- 展示品牌标题「失恋阵线联盟」。
- 展示产品一句话定位。
- 展示推荐阵线小队。
- 展示最新公开内容流。
- 提供进入 Agent 的快捷入口。
- 提供进入急性期支持的快捷入口。
- 提供进入联系决策辅助的快捷入口。

### 急性期支持

- 展示“先撑过 10 分钟”的冲动缓冲流程。
- 支持选择当前最强冲动：想联系 TA、深夜撑不住、一直自责、担心安全。
- 支持把想发出去的话先写下并本地保存，不实际发送。
- 支持查看最近暂存记录，点开后展示完整内容和安全提醒。
- 展示 10 分钟缓冲步骤。
- 展示紧急安全提醒。
- 当用户选择“担心安全”或输入高风险表达时，展示更醒目的安全提醒。
- 提供进入 Agent 和发布到阵线小队的后续入口。
- 提供进入联系决策辅助的后续入口。

### 联系决策

- 页面包含三个工具页签：联系判断、结构复盘、断联计划。
- 支持选择联系目的：想立刻发消息、想解释或道歉、想复合、想确认边界、有现实事务。
- 支持选择冲动强度。
- 支持标记是否有现实事务必须处理。
- 支持选择已经等待的时长。
- 支持把想发的话写成草稿。
- 提交后生成保守的下一步建议。
- 支持结构化关系复盘：事件、重复模式、双方需求、责任边界、支持/不支持联系的证据、带走的结论。
- 支持生成断联计划：断联周期、最危险时段、保护动作、断联目标、替代动作、破戒预案。
- 遇到高风险表达时优先展示安全提醒，不给联系建议。
- 保存本地复盘记录。

### 互助会

- 展示阵线小队列表。
- 支持按小队名称、简介、氛围和标签搜索。
- 支持加入或退出小队，状态会影响我的页和 Agent 可参考的小队公开内容范围。
- 展示小队主题、成员数、活跃状态和标签。
- 点击小队进入详情页。

### 阵线小队详情

- 展示小队简介、成员概览和公开内容。
- 支持加入或退出当前小队。
- 点击公开内容进入帖子详情。
- 提供发布入口。
- 提供跳转 Agent 的入口。

### 帖子详情

- 展示帖子正文、所属小队、情绪标签、发布时间和回应数。
- 展示已有回应。
- 支持输入并提交一条本地回应。
- 支持举报帖子或回应，举报进入待处理状态。

### 发布

- 支持内容类型：倾诉、复盘、求建议。
- 支持选择情绪标签。
- 支持选择可见范围，首版默认“小队可见”。
- 提交后给出本地成功反馈，并在本机保留。

### Agent

- 展示个人 Agent 对话。
- 展示上下文说明：Agent 会参考本人内容和小队公开内容。
- 支持发送消息并收到 mock 关怀回复。
- 用户发送后的对话在本机保留。
- 展示非医疗/心理咨询服务提示。
- 提供进入急性期支持的入口。

### 我的

- 展示登录状态、头像、昵称、当前阶段、个人备注、加入的小队、我的发布和 Agent 权限说明。
- 支持同步微信资料；授权失败时仍可手动编辑昵称和头像。
- 支持选择恢复阶段：急性期、复盘期、孤独期、重建期。
- 支持保存个人备注，帮助用户记录当前状态。
- 支持切回匿名资料。
- 展示非医疗/心理咨询服务提示。

## Tone

- 克制、温和、具体。
- 避免制造焦虑或承诺疗效。
- 避免诊断式语言。
- 鼓励复盘、互助和生活秩序重建。

## States

- 加载态：使用页面内简短提示。
- 空状态：告诉用户当前没有内容，并给出下一步入口。
- 错误态：首版仅使用 toast 或页面内提示。
