# Acceptance Spec

## Compile

- 微信开发者工具可以导入项目。
- 小程序可以编译运行。
- 控制台没有阻断首屏渲染的错误。

## Brand

- 全局导航标题使用「失恋阵线联盟」。
- 首页首屏展示「失恋阵线联盟」。
- 小组统一命名为“阵线小队”。

## Navigation

- 底部导航包含：首页、互助会、Agent、我的。
- 四个底部导航页可以正常切换。
- 首页可以进入小队详情和 Agent。
- 小队详情可以进入发布页和 Agent。

## Data Rendering

- 首页展示推荐小队和最新内容流。
- 互助会页展示小队列表。
- 小队详情展示小队信息、成员概览和帖子。
- Agent 页展示初始 mock 对话。
- 我的页展示用户资料、加入小队和权限说明。

## Interaction

- 发布页支持选择倾诉、复盘、求建议。
- 发布页支持选择情绪标签。
- 发布页输入正文后可提交并看到成功反馈。
- Agent 页输入消息后，用户消息追加到列表，并返回一条 mock 关怀回复。

## Safety

- Agent 页展示非医疗/心理咨询服务提示。
- 我的页展示非医疗/心理咨询服务提示。
