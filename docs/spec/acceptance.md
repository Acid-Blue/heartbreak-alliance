# Acceptance Spec

## Compile

- 微信开发者工具可以导入项目。
- 小程序可以编译运行。
- 控制台没有阻断首屏渲染的错误。

## Brand

- 全局导航标题使用「失恋阵线联盟」。
- 首页首屏展示「失恋阵线联盟」。
- 小组统一命名为“阵线小队”。

## Navigation

- 底部导航包含：首页、互助会、Agent、我的。
- 四个底部导航页可以正常切换。
- 首页可以进入小队详情和 Agent。
- 首页可以进入急性期支持页。
- 首页可以进入联系决策页。
- 小队详情可以进入发布页和 Agent。
- 首页、小队详情和我的发布可以进入帖子详情。
- Agent 页可以进入急性期支持页。
- 急性期支持页可以进入联系决策页。

## Data Rendering

- 首页展示推荐小队和最新内容流。
- 互助会页展示小队列表。
- 小队详情展示小队信息、成员概览和帖子。
- 帖子详情展示帖子正文和回应。
- 急性期支持页展示冲动类型、暂存输入框、10 分钟缓冲步骤和安全提醒。
- 联系决策页展示联系目的、冲动强度、现实必要性、等待时长、草稿输入和建议结果。
- Agent 页展示初始 mock 对话。
- Agent 页展示当前上下文授权范围。
- 我的页展示用户资料、加入小队和权限说明。

## Interaction

- 发布页支持选择倾诉、复盘、求建议。
- 发布页支持选择情绪标签。
- 发布页输入正文后可提交并看到成功反馈。
- 急性期支持页支持选择冲动类型，输入内容后可先存下并看到成功反馈。
- 急性期支持页在选择“担心安全”或输入高风险表达时展示醒目安全提醒。
- 联系决策页支持生成联系建议，并保存本地复盘记录。
- 联系决策页在输入高风险表达时优先生成安全提醒。
- 帖子详情输入回应后，回应追加到列表，帖子回应数更新。
- Agent 页输入消息后，用户消息追加到列表，并返回一条 mock 关怀回复。
- Agent 页输入高风险表达后，Agent 回复来源显示为“安全提醒”。
- 我的页可以开启或关闭 Agent 对本人发布/回应、小队公开内容的参考权限。
- Agent 回复来源说明会随权限开关变化。
- 重新进入小程序后，本机创建的帖子、回应和 Agent 对话仍可从本地存储恢复。
- 重新进入小程序后，本机保存的冲动缓冲记录数仍可恢复。
- 重新进入小程序后，本机保存的联系决策记录数仍可恢复。

## Safety

- Agent 页展示非医疗/心理咨询服务提示。
- 急性期支持页展示紧急安全提醒。
- 我的页展示非医疗/心理咨询服务提示。
