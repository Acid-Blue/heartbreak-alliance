# Acceptance Spec

## Compile

- 微信开发者工具可以导入项目。
- 小程序可以编译运行。
- 控制台没有阻断首屏渲染的错误。

## Brand

- 全局导航标题使用「失恋阵线联盟」。
- 首页首屏展示「失恋阵线联盟」。
- 小组统一命名为“阵线小队”。

## Navigation

- 底部导航包含：首页、互助会、Agent、我的。
- 四个底部导航页可以正常切换。
- 首页可以进入小队详情和 Agent。
- 首页可以进入急性期支持页。
- 首页可以进入联系决策页。
- 小队详情可以进入发布页和 Agent。
- 首页、小队详情和我的发布可以进入帖子详情。
- Agent 页可以进入急性期支持页。
- 急性期支持页可以进入联系决策页。
- 我的页可以进入内容治理页。

## Data Rendering

- 首页展示推荐小队和最新内容流。
- 互助会页展示小队列表。
- 互助会页展示搜索框，并可按小队名称、简介或标签筛选小队。
- 互助会页和小队详情页展示加入/退出小队状态。
- 小队详情展示小队信息、成员概览和帖子。
- 帖子详情展示帖子正文和回应。
- 急性期支持页展示冲动类型、暂存输入框、10 分钟缓冲步骤和安全提醒。
- 急性期支持页在深夜或选择深夜冲动时展示深夜模式，并展示安全计划编辑入口。
- 急性期支持页展示最近暂存记录，并支持点开查看全文。
- 联系决策页展示联系判断、结构复盘、断联计划、行动追踪四个工具页签。
- 联系判断页签展示联系目的、冲动强度、现实必要性、等待时长、草稿输入和建议结果。
- 结构复盘页签展示关系事件、重复模式、双方需求、责任边界、证据和结论输入。
- 断联计划页签展示断联周期、风险时段、保护动作、断联目标、替代动作和计划结果。
- 行动追踪页签展示行动计划、进度打卡、最近计划和 7 天周期回顾。
- Agent 页展示初始 mock 对话。
- Agent 页展示当前上下文授权范围。
- 互助会和小队详情展示阶段匹配、分享模板、正向回应引导和阶段打卡。
- 我的页展示登录状态、用户资料、加入小队、我的发布、生活重建和权限说明。
- 内容治理页展示举报记录和处理状态。

## Interaction

- 发布页支持选择倾诉、复盘、求建议。
- 发布页支持选择情绪标签。
- 发布页输入正文后可提交并看到成功反馈。
- 互助会页支持搜索小队。
- 互助会页和小队详情页支持加入/退出小队。
- 急性期支持页支持选择冲动类型，输入内容后可先存下并看到成功反馈。
- 急性期支持页支持保存可信赖联系人、安全地点和稳定动作。
- 急性期支持页保存后可以在最近暂存列表点开查看刚才写下的内容。
- 急性期支持页在选择“担心安全”或输入高风险表达时展示醒目安全提醒。
- 联系决策页支持生成联系建议，并保存本地复盘记录。
- 联系决策页支持生成结构化关系复盘，并保存本地复盘记录。
- 联系决策页支持生成 7/14/30 天断联计划，并保存本地复盘记录。
- 联系决策页支持生成行动计划、记录执行进度，并生成 7 天周期回顾。
- 联系决策页在输入高风险表达时优先生成安全提醒。
- 帖子详情输入回应后，回应追加到列表，帖子回应数更新。
- 帖子详情支持举报帖子和回应，并给出提交反馈。
- 举报后的内容应在本机隐藏，内容治理页可标记举报状态。
- 发布和回应输入敏感内容时应展示内容提示，命中规则的内容应进入审核态并不进入公开流。
- Agent 页输入消息后，用户消息追加到列表，并返回一条 mock 关怀回复。
- Agent 页输入高风险表达后，Agent 回复来源显示为“安全提醒”。
- 我的页可以选择头像、编辑昵称、选择当前阶段、填写个人备注并保存。
- 我的页可以尝试同步微信资料；授权不可用或取消时，应保留手动编辑路径。
- 我的页可以切回匿名资料。
- 保存昵称后，新发布的帖子和回应应使用当前昵称。
- 我的页可以开启或关闭 Agent 对本人发布/回应、小队公开内容的参考权限。
- 我的页可以选择 1-3 个生活重建小步，保存每日计划，记录完成情况和联系冲动强度。
- Agent 回复来源说明会随权限开关变化。
- 重新进入小程序后，本机创建的帖子、回应和 Agent 对话仍可从本地存储恢复。
- 重新进入小程序后，本机保存的个人资料仍可恢复。
- 重新进入小程序后，本机保存的冲动缓冲记录数仍可恢复。
- 重新进入小程序后，本机保存的关系复盘/断联记录数仍可恢复。
- 重新进入小程序后，本机保存的安全计划、行动追踪、生活重建和社群打卡记录仍可恢复。

## Safety

- Agent 页展示非医疗/心理咨询服务提示。
- 急性期支持页展示紧急安全提醒。
- 我的页展示非医疗/心理咨询服务提示。
